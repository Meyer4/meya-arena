Privacy Policy

Last updated: September 2026. Meya Arena ("the game") is developed as an independent project. This policy explains what data the game uses — in short: almost none.

1. Data we collect

None. Meya Arena does not create accounts, does not use analytics SDKs, does not serve ads, and does not transmit personal data to any server. Your hero progress, coins, rank, friends list and settings are stored only on your own device (browser local storage) and never leave it.

2. Permissions

The Android version requests Internet access only (to load the game engine on first launch). It does not request contacts, location, SMS, camera, microphone, or storage permissions.

3. Children

The game contains stylized fantasy combat with no graphic content. Since no personal data is collected, there is nothing to share, sell, or breach.

4. Future online play

When global multiplayer launches, accounts (via Firebase Authentication) and match data will be required to connect players. This policy will be updated before that release, and online play will remain optional — offline bot matches will always work without an account.

5. Contact

Questions about this policy: contact the developer through the website hosting this page.
